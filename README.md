## API (POST JSON, `token` חובה)
| action | פרמטרים | מה עושה |
|---|---|---|
| `list` | – | כל ההזמנות הפעילות + summary |
| `add` | `booking`, `replaceId?` | מוסיף. עם replaceId — הישנה עוברת להיסטוריה כ"הוחלף" |
| `upsert` | `booking`, `replaceId?` | לרוברט: מזהה הזמנה קיימת לאותו מלון ומחליף; אם יש כמה — מחזיר `candidates` |
| `update` | `id`, `booking` (שדות חלקיים) | עדכון במקום + רישום השינויים בהיסטוריה |
| `delete` | `id`, `note?` | מוחק מהרשימה, שומר בהיסטוריה |
| `restore` | `id` | מחזיר רשומה מחוקה/מוחלפת |
| `history` | `limit?` | ההיסטוריה (חדש→ישן) |
| `setTarget` | `nights` | יעד לילות (ברירת מחדל 21) |

GET עובד ל-`list`/`history`/`get` עם `?action=..&token=..`. `?action=ping` פתוח לבדיקת חיים.

**curl:** `curl -sL "$URL" -H "Content-Type: text/plain" -d '{...}'` — בלי `-X POST` (אחרת ה-redirect של Apps Script מחזיר HTML).

**הטוקן לא בריפו.** באפליקציה מזינים אותו פעם אחת ב-⚙ הגדרות, או פותחים פעם אחת `index.html?token=...` (נשמר במכשיר ונמחק מהכתובת). `robert/SKILL.local.md` (עם הטוקן) מחוץ ל-git.
